# Déploiement Render

Cette version ne dépend d'aucun package npm serveur. Le frontend est déjà compilé dans `frontend/dist`.

Paramètres Render recommandés :

- Environment: Node
- Build Command: `npm run build`
- Start Command: `npm start`
- Node: `20.x`

Si Render affiche encore un cache npm étrange, clique sur **Clear build cache & deploy**.
